## Architectural & Research Specification

Model 4 decouples MRI-to-CT translation into a two-stage residual refinement framework:
1. **Stage 1 (Coarse Anatomical Regression):** A 4-fold patient-level cross-fitted ResUNet predicting coarse CT $c = G_\phi(\text{MRI})$.
2. **Stage 2 (Residual Conditional Diffusion Refinement):** A 4-channel conditional diffusion denoiser $[z_t, \text{MRI}, c, \text{mask}]$ modeling normalized Out-Of-Fold residuals $z_0 = (y - c_{\text{OOF}}) / s$.

### Key Protocol Standards
- **Zero In-Sample Leakage:** The diffusion model is trained exclusively on out-of-fold coarse predictions. Each training patient's coarse CT is generated by a ResUNet instance trained on the other 3 folds.
- **Ensemble Validation/Test:** For validation and test patients, coarse CT is generated by the ensemble mean of all 4 fold models: $c = \frac{1}{4} \sum_{k=1}^4 G_{\phi_k}(\text{MRI})$.
- **No Clean-CT Clamping on Residuals:** The normalized residual $z_0$ is unconstrained during DDIM reverse sampling. Final CT is formed via $\text{sCT} = \text{clip}(c + s \cdot z_0, -1, 1)$.
- **Strict Test Isolation:** The 6 held-out test patients remain completely frozen and are never accessed during cross-fitting, residual scaling, training, or checkpoint selection.

## How to Run on Kaggle

### Step 1: Upload Notebook to Kaggle
1. Open Kaggle and navigate to **Code** -> **New Notebook**.
2. Click **File** -> **Import Notebook** and select `SynthRAD_Model4_CrossFitted_Residual_Diffusion.ipynb`.

### Step 2: Attach Dataset
1. In the right panel, click **+ Add Input**.
2. Search for the SynthRAD2023 PNG dataset:
   `lohithkgowda/synthrad2023-brain-2d-png`
3. Verify that the input path is:
   `/kaggle/input/datasets/lohithkgowda/synthrad2023-brain-2d-png/synthrad_png`

### Step 3: Select Accelerator
1. In the right settings panel, select **GPU P100** or **GPU T4 x2**.
2. Verify Internet is enabled (optional, for package checks).

### Step 4: Execute Cells Sequentially
The notebook contains modular execution flags in Cell 2:
- `RUN_COARSE_TRAINING = True` (Trains 4-fold ResUNets; automatically skips if checkpoints exist).
- `RUN_RESIDUAL_TRAINING = True` (Trains Stage 2 residual diffusion).
- `RUN_OPTIONAL_ABLATIONS = False` (Optional ablation studies E0, E2, E4, E5).
- `RUN_FINAL_TEST_EVALUATION = False` (Kept False by default to preserve test set isolation).

Execute cells 1 through 18. Deliverables will be automatically archived into:
`/kaggle/working/synthrad_model4_residual_diffusion_deliverables.zip`
